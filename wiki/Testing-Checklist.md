# Quick Installation Check

The former technical release-testing page has been replaced with a short user check.

1. Start a harmless local website or API and confirm it opens directly in your browser.
2. Open GhostlyShare and wait for its app card.
3. Start a LAN share and open it from another device on the same trusted network.
4. Stop LAN sharing.
5. Start a temporary public share, test it from another browser, and stop it.
6. Fully quit and reopen GhostlyShare.
7. If the app is missing or a link fails, follow [Troubleshooting](Troubleshooting.md).

CLI users can verify the installed command with:

```bash
ghs version
ghs scan
```

Do not use private admin panels, real customer data, or production credentials for this check.
