# Reporting Bugs and Feature Requests

Use the public issue forms in this release repository:

- [Report a bug](https://github.com/Nix1983/GhostlyShare-Releases/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/Nix1983/GhostlyShare-Releases/issues/new?template=feature_request.yml)

A GitHub account is required to submit an issue.

## A Useful Bug Report

Include:

- GhostlyShare version from **About** or `ghs version`.
- Windows or Linux distribution.
- On Linux, the desktop environment and whether the session uses Wayland or X11.
- Desktop app or CLI.
- What you expected and what happened.
- The smallest steps that reproduce the problem.
- Exact error text.
- A screenshot when it helps.
- For a missing app, its local URL, framework, and the safe reason from Discovery diagnostics.
- For Public, whether the link is Random or Custom and whether the local app still opens.
- For LAN, whether the devices use the same network and whether a VM or VPN is involved.

## Protect Private Information

Do not post:

- Cloudflare API tokens.
- Public-link or LAN passwords.
- Private URLs that should not be shared.
- Customer, personal, or confidential data.
- Complete logs or screenshots containing secrets.

Redact sensitive values before uploading anything.

## A Useful Feature Request

Describe the user problem, the behavior you expected, the affected platform, and why the current workflow is not sufficient. Focus on the result for users rather than an internal implementation.
